01

История и философия Go

Go — компилируемый, статически типизированный язык со встроенной конкурентностью. Google разрабатывала его с 2007 года не только ради производительности высоконагруженных серверов, но и ради продуктивности самих разработчиков. Массовую популярность язык начал набирать примерно с 2012 года — и с тех пор не сбавляет темп.

У Google было чёткое техническое задание. Язык должен быть максимально простым в изучении и в бою. Поэтому в его дизайне сознательно отказались от классического ООП с наследованием и иерархиями классов в пользу более простых механизмов — структур и интерфейсов (о них ещё поговорим). Авторы языка — Роберт Гризмер, Роб Пайк и Кен Томпсон — до Go успели написать компиляторы на C++ и поработать над Unix и Plan 9. Из этого опыта в Go перекочевали:

  • быстрая компиляция;
  • кросс-платформенность — сборка под любую ОС и архитектуру из одного исходника;
  • богатая стандартная библиотека — включая сеть и тестирование из коробки;
  • автоматическое управление памятью через сборщик мусора;
  • конкурентность как часть языка, а не надстройка над ним.

Плюсы

  • Низкий порог входа
  • Статическая типизация — ошибки ловятся на компиляции
  • Простой, минималистичный синтаксис
  • Богатая стандартная библиотека
  • Многопоточность на уровне языка — горутины
  • Самодостаточность и кросс-платформенность
  • Автоматическая работа с памятью

Минусы

  • Нет классического ООП
  • Осознанный отказ от привычных концепций (дженерики появились лишь пару лет назад)
  • Нишевость — силён в бэкенде и облаке, слаб вне этой области
  • Статическая типизация — да, и это тоже минус
// на заметку

Статическая типизация — одновременно и в плюсах, и в минусах. Это две стороны одной монеты: она ловит ошибки на этапе компиляции ценой того, что динамическая типизация порой позволяет писать быстрее и лаконичнее.

03

Первая программа: Hello World

Окружение готово — пишем первую программу. Создай файл hello_world.go с приветствием:

hello_world.gogo
package main

import "fmt"

/*
	Многострочный
	комментарий
*/

func main() {
	fmt.Println("Hello, world!") // Выводим в консоль
}

Разберём код по частям:

package
Базовая единица любого Go-кода. Пакеты — основной способ организации кодовой базы, обычно по функционалу. package main обязателен в любой программе (не библиотеке) — это точка входа. Пакет ограничивает видимость неэкспортируемых имён своими границами.
import
Подключает код одного пакета в другой. Здесь мы импортируем fmt из стандартной библиотеки — пакет для форматирования данных.
func main() {...}
Функция, с которой начинается выполнение любой программы. Без неё приложение не запустится. Обрати внимание: строки кода ничем не заканчиваются — точку с запятой Go расставляет сам на этапе компиляции.
// и /* */
Однострочные и многострочные комментарии — оба варианта поддерживаются нативно.
// программы vs библиотеки

В программах и сервисах всегда есть пакет main с одноимённой функцией — точкой входа. Библиотеки же — это набор пакетов, объединённых одной логикой, без main, созданный ради конкретного функционала (обработка строк, конвертация форматов и т. д.). Эталонный пример — сам исходный код Go.

04

Сборка и кросс-платформенная разработка

Написать программу мало — её нужно скомпилировать и запустить, чтобы убедиться в отсутствии ошибок:

терминалbash
go build hello_world.go

Команда соберёт исполняемый файл под ту ОС и архитектуру, в которой она выполняется (для Windows это будет hello_world.exe). Запусти файл — увидишь результат в консоли.

Кросс-платформенность в других языках часто даётся через боль. В Go это пара переменных окружения перед той же командой:

  • GOOS — целевая операционная система;
  • GOARCH — целевая архитектура.
терминалbash
GOOS=windows GOARCH=amd64 go build hello_world.go

Не укажешь переменные — компилятор сам определит параметры текущей системы.

Но чаще всего в разработке нужен более быстрый цикл:

терминалbash
go run hello_world.go

05

Форматирование

Go требователен к стандарту оформления кода — и именно это делает любую чужую (и свою старую) Go-кодовую базу читаемой. Инструмент для авто-форматирования встроен из коробки:

терминалbash
go fmt ./...

Команда приводит отступы, пробелы и переносы строк к единому стилю, а заодно убирает лишние пробелы и причёсывает выражения.

06

Переменные окружения

Go активно использует переменные окружения — пары «ключ – значение», хранящиеся в ОС, — чтобы настраивать собственное поведение. Посмотреть текущее состояние своих Go-переменных можно так:

терминалbash
go env

В терминале появится список переменных и их текущих значений — это знание ещё пригодится нам в настройке языка.

07

Переменные и типы данных

Базовые типы

Как и в любом языке, в Go есть набор фундаментальных типов, с которыми мы будем работать весь курс: целые числа, числа с плавающей точкой, логический тип и строки.

Целые числа

Бывают со знаком и без — int и uint соответственно. Важна разрядность: int8 — целое со знаком на 8 бит, а без указанной разрядности (просто int) компилятор сам подберёт 32 или 64 бита в зависимости от архитектуры сборки.

ТипОписаниеПримеры
intЗависит от архитектуры (32/64 бита)42, -10
int32от −2 147 483 648 до 2 147 483 647-100000, 2147483647
int64от −9 223 372 036 854 775 808 до 9 223 372 036 854 775 807-5000000000
uintБеззнаковое, зависит от архитектуры0, 100256
uint32от 0 до 4 294 967 2950, 42
uint64от 0 до 18 446 744 073 709 551 6150, 101

Числа с плавающей точкой

Два типа: float32 (6–7 значащих цифр) и float64 (15–17 значащих цифр), оба по стандарту IEEE 754. Первый — когда точность не критична, второй — выбор по умолчанию для большинства вычислений.

// важно

Эти типы не годятся для денег и финансовых расчётов. Подумай, почему — и загляни в источники внизу за подсказкой про представление дробей в двоичном виде.

ТипОписаниеПримеры
float32Одинарная точность (32 бита)3.14, -0.0001
float64Двойная точность (64 бита)3.141592653589793

Логический тип

bool — 1 байт, значения true или false. Строго отделён от чисел: попытка подставить 1 и 0 вместо true/false — ошибка компиляции, а не «сработает как в C».

Строки

Под капотом string — это последовательность байтов. Формально кодировка не навязывается, но по умолчанию ожидаются UTF-8-байты, представляющие Unicode-кодовые точки. По строке можно пройтись циклом:

main.gogo
for i, ch := range "hello" {
	fmt.Println("Номер: ", i, ", символ: ", ch)
}

В выводе будут не буквы, а числа — Unicode-коды символов (101 — код латинской e). А если заменить латиницу на кириллицу, индексы «поедут»:

range "hi" — латиница

  1. индекс 0символ 104 (h)
  2. индекс 1символ 101 (e)
  3. индекс 2символ 108 (l)
  4. индекс 3символ 108 (l)
  5. индекс 4символ 111 (o)

range "hи..." — кириллица

  1. индекс 0символ 104 (h)
  2. индекс 1символ 1077 (е)
  3. индекс 3символ 108 (l) ← не 2!
  4. индекс 4символ 108 (l)
  5. индекс 5символ 111 (o)

Причина — кириллица кодируется двумя байтами, и Go честно отражает это в индексах при обходе строки.

Строка — массив байтов, поэтому к её элементам можно обращаться по индексу. Но так ты получишь доступ не к символу, а к конкретному байту — будь внимателен. А чтобы узнать количество байтов, используется len():

main.gogo
package main

import "fmt"

func main() {
	fmt.Println(len("hello"))
	fmt.Println(len("привет"))
}
// подвох

Ожидаешь 5 и 6? Получишь 5 и 12. Каждый символ кириллицы кодируется двумя байтами, и len() честно считает именно байты, а не буквы. Способ посчитать реальное число символов — отличная тема для самостоятельного поиска.

Самое важное: строки в Go неизменяемы. Изменить символ по индексу нельзя. Конкатенация не «дописывает» в существующую строку — она создаёт новую:

main.gogo
s1 := "Строка "
s2 := "и еще строка"
s1 = s1 + s2
fmt.Println(s1)

Результат ожидаем, но под новое значение выделяется новая область памяти. Если конкатенация происходит часто, в пакете strings стандартной библиотеки есть Builder, ускоряющий именно этот сценарий — там же масса других полезных функций для строк.

Более хитрые типы

В Go есть типы-синонимы — синтаксические обёртки над уже знакомыми типами:

ТипОписаниеПримеры
byteСиноним uint8, представляет байт'a', 97
runeСиноним int32, представляет Unicode-символ'ы', 0x0000044B

Руна — это как раз то, что мы получаем, проходя циклом по строке: Go склеивает байты в единый символ (напомним, кириллица — два байта), и с руной уже можно работать как с отдельным символом.

Способы определения переменных

Классическое полное определение — с ключевым словом, именем, типом и значением:

main.gogo
var i int = 1
var w float64 = 12.5

Тип нужен только тогда, когда он не выводится автоматически из значения (или должен отличаться от вывода по умолчанию), поэтому его часто опускают:

main.gogo
var i = 1         // int
var w = 12.5      // float64
var name = "John" // string

Если значения нет, переменная получает «нулевое» значение для своего типа:

main.gogo
var i int          // 0
var w float64      // 0.0
var isPresent bool // false
var name string    // ""
// zero value

Переменная, объявленная без инициализации, автоматически получает «нулевое значение» своего типа. Так в Go в принципе не существует неинициализированной памяти — переменной безопасно пользоваться сразу после объявления.

Несколько переменных можно объявить одним блоком:

main.gogo
var i, j, k int = 1, 2, 3
var (
	name       string = "John Doe"
	occupation string = "gardener"
)

И самый частый в реальном коде вариант — короткое объявление через :=:

main.gogo
name := "John Doe"
age := 34

Обрати внимание — это именно :=, а не =, как в Python.

Преобразование типов

В Go нет неявных преобразований между типами — целевой тип всегда указывается явно:

main.gogo
var i = 1
var v float64 = float64(i)

Константы

Неизменяемые значения, вычисляемые на этапе компиляции, объявляются через const:

main.gogo
const Pi = 3.14159

const name string = "My name"
const surname = "My surname"

const (
	StatusOK       = 200
	StatusNotFound = 404
)

Тип константы можно указать явно — а можно доверить его Go, если он не принципиален.

Области видимости и экспортируемость

Область видимости — участок кода, где переменная, функция или константа остаются доступными. Для переменных внутри функции область видимости ограничена телом самой функции — фигурными скобками {}.

Экспортируемость определяется регистром первой буквы имени. Имя с большой буквы — элемент экспортируемый, доступен из других пакетов проекта. Имя с маленькой — виден только внутри своего пакета.

08

Управляющие конструкции

if / else

Ветвление позволяет выполнять код при выполнении условия. Условно: если тебя просят купить хлеб, а если найдётся ещё и колбаса — взять и её, псевдокодом это выглядело бы так:

мысленный примерне Go
покупки := func КупитьХлеб()

if есть колбаса {
	покупки + колбаса
}

А вот так это выглядит по-настоящему:

main.gogo
x := 10

if x > 5 {
	fmt.Println("x больше 5") // Текст выведется в консоль
}
  • условие if обязано быть выражением типа bool — неявных преобразований нет;
  • условие не нужно оборачивать скобками, в отличие от многих C-подобных языков;
  • переменные внутри тела блока видны только внутри этого блока;
  • переменные, объявленные в условии оператора, видны во всей конструкции, но не за её пределами.

Отдельная удобная возможность — объявить и инициализировать переменную прямо в условии:

main.gogo
if x := getValue(); x > 0 {
	fmt.Println("Положительное значение:", x)
}
// x здесь уже недоступна

Это дополнительно сужает область видимости до того единственного места, где переменная действительно нужна. Для нескольких условий — цепочка else if:

main.gogo
if x > 0 {
	fmt.Println("Положительное")
} else if x < 0 {
	fmt.Println("Отрицательное")
} else {
	fmt.Println("Ноль")
}
// когда стоп

Длинная цепочка else if быстро превращается в нечитаемую лестницу:

if x == 1 {...} else if x == 2 {...} else if x == 3 {...}
else if x == 4 {...} else if x == 5 {...} else if x == 6 {...}

Если вариантов много — время переходить на switch.

switch

switch нужен, когда нужно выбрать один из множества сценариев, и делает такой выбор гораздо читаемее:

main.gogo
switch time.Now().Weekday() {
case time.Saturday:
	fmt.Println("Today is Saturday")
case time.Sunday:
	fmt.Println("Today is Sunday")
default:
	fmt.Println("Today is a working day")
}
  • switch держит значение, с которым сверяются все ветки;
  • case — варианты выбора; проверяются по порядку сверху вниз, первое совпадение выполняется и конструкция завершается;
  • default перехватывает всё, что не подошло ни под один case — необязателен, но хороший тон и подстраховка от забытых сценариев.

switch может быть и без значения — тогда это эквивалент switch true, и в case можно писать условия, а не значения:

main.gogo
hour := time.Now().Hour()
switch {
case hour < 12:
	fmt.Println("Good morning!")
case hour < 17:
	fmt.Println("Good afternoon!")
default:
	fmt.Println("Good evening!")
}

Управлять выполнением можно ещё двумя операторами: break выходит из switch досрочно, а fallthrough — в конце блока case — выполняет следующую ветку без проверки её условия. Так можно собирать зависимые друг от друга цепочки кейсов.

09

Множественные выражения

Когда нужно проверить сразу несколько условий, на помощь приходят логические операторы:

&&

И

true, если истинны оба значения.

isUser := true
isAdmin := true

if isUser && isAdmin {
	fmt.Println("Operation completed")
}
||

ИЛИ

true, если истинно хотя бы одно значение.

isClosed := true
isWeekend := false

if isClosed || isWeekend {
	fmt.Println("You can't order now")
}
!

НЕ

Инвертирует значение выражения.

isClosed := true
isWeekend := true

if !(isClosed || isWeekend) {
	fmt.Println("You can order now")
}
10

Циклы

В отличие от многих C-подобных языков, в Go для циклов используется только один оператор — for. Отдельного while в языке идеологически нет: всю функциональность закрывают четыре формы того же for.

Полная форма (C-style)

Инициализация, условие и шаг — всё в заголовке.

main.gogo
sum := 0

for i := 1; i < 5; i++ {
	sum += i
}

fmt.Println(sum) // 10

Только условие (аналог while)

Инициализация и шаг опущены — остаётся условие.

main.gogo
n := 1

for n < 5 {
	n *= 2
}

fmt.Println(n) // 8

Бесконечная форма

Все три части заголовка опущены.

main.gogo
sum := 0

for {
	sum++
	fmt.Println(sum) // «бесконечно» пишем числа
}

for-range

Для обхода строк, массивов, мап и других структур.

main.gogo
for i, ch := range "hello" {
	fmt.Println("Индекс: ", i, ", значение: ", ch)
}

Итерирование по целым числам появилось только в Go 1.22:

main.gogo
for i := range 5 {
	fmt.Println(i) // 0, 1, 2, 3, 4
}

// аналог:
for i := 0; i < 5; i++ {
	fmt.Println(i)
}

Цикл в цикле — практика, которой стоит по возможности избегать, но иногда без неё не обойтись. Чтобы прервать сразу все вложенные циклы, а не только внутренний, используются метки:

main.gogo
sum := 0

outer:
for {
	sum++
	for j := 0; j < sum; j++ {
		if j*sum == 111 {
			break outer // выходим из ОБОИХ циклов разом
		}
	}
}

Без метки break прервал бы только внутренний цикл, вернув выполнение во внешний бесконечный for.

Если текущая итерация уже отработала своё и нужно перейти к следующей — continue:

main.gogo
sum := 0

for i := 1; i < 5; i++ {
	if i%2 != 0 {
		continue // пропустить нечётные
	}

	sum += i
}

fmt.Println(sum) // 6 (2+4)

А если из пары «индекс + значение» нужен только один элемент — второй опускается через _:

main.gogo
strings := [3]string{"I", "love", "Go"} // массив — познакомимся ближе в следующей главе
for i := range strings {
	fmt.Println(strings[i])
}

// или только по значению:
for _, s := range strings {
	fmt.Println(s)
}
